# Соглашение о коммитах

Соревновательная часть: 23.09.2026, 13:00–18:00 (Астана).

## Формат сообщения

```
<тип>(<область>): <описание в повелительном наклонении>

Час: <1-5>
AI: <да|нет> — <что именно сгенерировано>
Проверка: <команда или шаг, которым проверен результат>
```

## Типы

| Тип | Когда |
|---|---|
| `feat` | новая функциональность |
| `fix` | исправление |
| `docs` | README, документация, схемы |
| `infra` | окружение, зависимости, конфигурация, скрипты запуска |
| `data` | тестовые данные, фикстуры, схемы данных |
| `test` | проверки основного сценария |
| `progress` | почасовая контрольная точка (п. 5.4.8) |

## Правила

1. Коммит каждые 10–15 минут. Незавершённый код коммитим тоже.
2. Каждый участник коммитит под своей учётной записью git, с email,
   указанным при регистрации на edu.astanahub.com.
3. Парная работа помечается трейлером
   `Co-authored-by: Имя Фамилия <email>`.
4. История не переписывается: без `--force`, `rebase`, `squash`, `amend`.
5. Слияние веток только `--no-ff`.
6. В конце каждого отчётного часа — коммит типа `progress`
   с обновлённым `PROGRESS.md`.
7. Разработка ведётся только в репозитории, созданном Организатором
   (п. 5.4.9, 5.4.11).
8. Последний коммит до 18:00 — финальная версия README
   после проверки запуска из чистого клона.

## Примеры

```
feat(agent): добавить цикл вызова инструментов с ограничением итераций

Час: 2
AI: да — каркас цикла; ограничение итераций и таймаут написаны вручную
Проверка: основной сценарий проходит от запроса до результата
```

```
progress(hour-4): контрольная точка, обработка некорректного ввода

Час: 4
AI: нет
Проверка: PROGRESS.md обновлён, .env.example заполнен
```

```bash
git config user.name "Имя Фамилия"
git config user.email "email@из.регистрации"
git log --format='%an <%ae>'   # после первых коммитов
```
